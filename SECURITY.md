# Security Policy

## Purpose
This repository contains intentionally vulnerable code designed solely for educational and security training purposes.

## ⚠️ WARNING: DO NOT RUN IN PRODUCTION
The code in this repository is inherently insecure. It contains multiple vulnerabilities (Cross-Site Request Forgery, etc.) specifically engineered to demonstrate attack vectors.
- **NEVER** deploy this code to a public-facing web server.
- **NEVER** use this code as a base for production applications.
- **ALWAYS** run this lab in an isolated, sandboxed environment (e.g., Docker container, local virtual machine, or local development machine without sensitive data).

## Reporting Security Issues
This is an educational project. If you find a security issue in the *lab structure itself* that allows it to be used for malicious purposes beyond its intended scope, please report it via GitHub Issues.
